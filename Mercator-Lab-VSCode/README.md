# Mercator Lab — проект для VS Code

Это исходный код текущего сайта: те же страницы, оформление, расчёты и интерактивная 3D-лаборатория. Проект статический; специальные фреймворки и сервер не нужны. Папка не привязана к ChatGPT Sites и готова к загрузке в собственный GitHub-репозиторий.

## Открыть сайт в VS Code на Windows

1. Распакуйте архив `Mercator-Lab-VSCode.zip` в удобную папку.
2. Откройте VS Code → **File → Open Folder…** и выберите распакованную папку `Mercator-Lab-VSCode`.
3. Откройте терминал VS Code: **Terminal → New Terminal**.
4. Запустите локальный сервер из корневой папки проекта:

   ```powershell
   python -m http.server 8000 --directory dist
   ```

   Если команда `python` не найдена, попробуйте `py -m http.server 8000 --directory dist`.
5. Откройте в браузере <http://localhost:8000>. Для вращающейся 3D-модели браузер должен поддерживать WebGL.
6. Чтобы остановить сервер, вернитесь в терминал и нажмите **Ctrl+C**.

Запускайте через сервер, а не двойным нажатием на `index.html`: сайту нужны локальные HTTP-запросы для карты Земли и браузерные API. Установка Node.js нужна только для тестов или офлайн-сборки.

## Опубликовать на Vercel со своим GitHub

1. В VS Code откройте папку проекта и сохраните файлы.
2. Создайте **свой** новый пустой репозиторий на GitHub.
3. В терминале проекта выполните команды GitHub, показанные для нового репозитория, или используйте **Source Control** в VS Code, чтобы закоммитить файлы и отправить их в GitHub.
4. Войдите в Vercel со своим аккаунтом, импортируйте ваш репозиторий и опубликуйте его. `vercel.json` уже указывает папку сайта `dist` и пустые команды установки/сборки: отдельная сборка этому HTML/CSS/JS-проекту не нужна.
5. Vercel выдаст собственный адрес проекта. Если у вас есть отдельный домен, его можно подключить позднее в настройках Vercel.

Исходники позволяют открыть и изменять проект. Не указывайте на конкурсе, что вы самостоятельно написали каждую строку, если часть кода была подготовлена с помощью ИИ; точнее сказать, что вы собрали и доработали сайт с помощью кодирования и ИИ-инструментов.


Научная лаборатория на казахском и русском языках. Главная страница с выбором четырёх независимых разделов:

- `dist/lab.html`: связанный глобус и карта, масштаб точки, площадь страны, сравнение территорий, CSV.
- `dist/experiments.html`: равновеликие ячейки и сравнение физических измерений с теорией.
- `dist/surfaces.html`: Surface Unfolding Lab — настоящие 3D-сетки WebGL, изометрические развёртки цилиндра и конуса, жёсткие грани куба, деформация сферы, эксперимент об идеальной карте.
- `dist/method.html`: формулы, источники, ограничения и встроенная проверка площадей.

Язык сохраняется между страницами в localStorage; приложение также работает при недоступном localStorage. `guide.html` перенаправляет на методику.

## Запуск

Откройте опубликованный сайт либо запустите `python -m http.server 8000 --directory dist` и откройте http://localhost:8000. Для 3D нужен WebGL. Сборщик и серверная часть приложению не нужны.

3D-геометрия и расчёты работают без внешнего движка. Данные географии и текстура Земли загружаются в браузере: D3 7.9.0, topojson-client 3.1.0, world-atlas 2.0.2 (jsDelivr, резервный источник unpkg). Текстура строится на canvas по реальным географическим полигонам Natural Earth. При сбое сети выводятся статус и кнопка повтора; 3D-модели остаются доступными. Текстура Земли отсутствует до успешной загрузки геоданных.

## Проверка

    npm test

Без установки зависимостей выполняются:

    node science/test.mjs
    node science/test-surfaces.mjs
    node science/test-surface-mesh.mjs
    python science/check-pages.py

Основной математический тест проверяет контрольные значения Mercator, симметрию, исключение полюсов, производную, равенство площадей ячеек, сферический избыток и переход через 180°.

Проверки развёрток сравнивают метрику с независимыми центральными конечными разностями на разных стадиях анимации, проверяют длины и шарниры куба, коэффициенты искажения сферы, зазоры и плоские конечные состояния. Тест сеток проверяет допустимость индексов, конечность координат, планарность конечных состояний и погрешность аппроксимации гладкой поверхности.

В интерфейсе доступны отдельные кнопки проверки метрики и сравнения площадей D3 с независимым граничным интегралом. В среде разработки браузерный просмотр недоступен: визуальная работа WebGL и загрузка CDN не проверены в браузере. Успешные математические тесты этого не заменяют.

## Геометрия Surface Unfolding Lab

Все размеры моделей условные. Единичная сфера имеет R=1; цилиндр r=1, h=2; конус r=1, L=2; куб a=1. Камера автоматически подбирает расстояние по габаритам; видимый размер и площадь в пикселях не являются геометрической мерой.

- **Куб:** 7 разрезанных рёбер, 5 шарниров. Каждая грань движется как жёсткое тело; общий шарнир остаётся совпадающим при любом t. Конечный результат — крест из шести квадратов.
- **Цилиндр:** только боковая поверхность. При b=1−t используется F(u,v)=(r sin(bu)/b, v, r(cos(bu)−1)/b+br). Предел при t=1 равен (ru,v,0). Во все моменты E=r², F=0, G=1.
- **Конус:** только боковая поверхность. q₀=r/L, q=q₀+(1−q₀)t, β=q₀θ/q. До жёсткого движения F=(ρq sinβ, ρq cosβ, ρ√(1−q²)); метрика dρ²+(q₀ρ)²dθ² постоянна. Финальный сектор имеет угол 2πr/L и радиус L. Вершина исключается из гладкого метрического утверждения.
- **Сфера / полосы:** N меридиональных разрезов и прерванная синусоидальная проекция x=λc+(λ−λc)cosφ, y=φ. Финальная площадь сохраняется (K_A=1), но вне центрального меридиана и экватора есть сдвиговая деформация. Для a=(λ−λc)sinφ главные масштабы σ±=(√(4+a²)±|a|)/2. Зазор между соседними полосами на широте φ равен (2π/N)(1−cosφ). Сами зазоры не измеряют изменение длины или площади.
- **Сфера / Mercator:** x=λ, y=asinh(tanφ), |φ|≤85°. k=secφ, K_A=sec²φ. Полюса исключены и не получают конечной координаты.
- **Анимация сферы:** F_t=(1−t)F_sphere+tF_flat — деформирующая интерполяция, не изометрическое разворачивание. Промежуточные состояния могут сжиматься и вырождаться; они не рассматриваются как физическое движение нерастяжимой оболочки. В режиме полос площадь сохраняется только в конечном состоянии и в исходном состоянии, не на всей траектории.

Цвет на каждой вершине вычисляется по двум сингулярным числам дифференциала текущего преобразования в ортонормированном базисе исходной сферы. Зелёный — 1, синий — сжатие, оранжевый — растяжение. Выбирается большее по модулю логарифмическое отклонение; при равенстве выбран цвет растяжения. Насыщение при коэффициенте 4 или 1/4. В локальном измерителе оба масштаба и их произведение показаны отдельно. Жёлтая точка обозначает выбранное место; оно может быть скрыто обратной стороной фигуры.

Гладкие формулы изометричны для цилиндра/конуса, треугольная визуализация — их конечная аппроксимация. Малая разница длин хорд соседних вершин при изгибании не равна деформации гладкой поверхности. Текстура на кубе/цилиндре/конусе иллюстрирует прикреплённый материал, а не новую географическую проекцию с заявленными свойствами.

Гауссова кривизна обозначена K_G, коэффициент площади — K_A (Kₐ в интерфейсе). В основном калькуляторе сохранено обозначение K для коэффициента площади. Это разные величины. Гладкая сфера K_G=1/R² не локально изометрична плоскости K_G=0. Куб имеет плоские грани и сосредоточенный угловой дефект π/2 в каждой вершине; у конуса дефект вершины равен 2π(1−r/L).

## Основная модель Mercator

R = 6371.0088 км; нормировка по экватору k₀=1. На сфере A=R²Ω по геодезическому многоугольнику D3. В Mercator Aₘ определяется по адаптивно уточнённым границам. K̄=Aₘ/A — среднее с весами по площади, а не подстановка широты центра.

D3 использует масштаб проекции 1 и допуски 1e-5 / 2.5e-6. Разность результатов показывает численную сходимость и не является абсолютной оценкой географической точности.

Независимая проверка использует −R²∮sinφ dλ и −R²∮asinh(tanφ) dλ по геодезическим границам; трапецеидальная квадратура с шагом 0.1 и 0.025 градуса дуги. Разности долгот нормализованы через 180°. Отверстия вычитаются, компоненты суммируются. Контуры, охватывающие полюс, исключены. Полная площадь изображения Антарктиды бесконечна. Визуальная карта ограничена ±85.05112878°, численный расчёт остальных территорий использует полные границы, не canvas.

Natural Earth 110m содержит обобщённые границы. Модельные площади не заменяют официальные площади стран. «Африка» объединяет представленные африканские территории; мелкие острова могут отсутствовать. WGS84 здесь не реализован.
